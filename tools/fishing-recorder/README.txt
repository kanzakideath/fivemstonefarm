釣り記録ツール 1.0.0
===================
これは手動プレイを記録するだけの独立ツールです。採掘機本体の更新ではありません。
自動入力、釣り判定への介入、ゲームメモリ操作、サーバー変更、ネット通信はしません。
Windows 10/11 x64 + .NET Framework 4.8用。Python・録画ソフトのインストールは不要です。

最初に
------
1. ZIPを展開して FishingRecorder.exe を開きます。
2. 既存のAI採掘機の自動操作はF9で止めてください。
3. FiveMをウィンドウ表示かボーダーレス表示にし、手動で釣れる場所へ行きます。
4. 記録ツールの「記録開始（3秒後）」を押して、FiveMへ戻ります。
5. 普段どおり2で釣り竿を使い、画面の数字をタイミングよく押してください。
   追加の数字が出たら、それも普通に押します。失敗しても記録をやり直さなくて大丈夫です。
6. 2〜3分、可能なら3〜5匹分の一連の流れを記録します。
   魚を釣った後、次の2を押して再開するところまで含めてください。
7. Ctrl + Alt + F9 で終了・保存。保存フォルダーが開き、共有用ZIPが選択されます。
8. FishingSample-日時-識別子.zip を、このChatGPTチャットへ添付してください。

ショートカット
--------------
Ctrl + Alt + F8  開始（3秒後）／記録中は一時停止と再開
Ctrl + Alt + F9  記録終了・ZIP保存
Ctrl + Alt + F10 任意の目印（成功・失敗は自動判定しません）
ショートカットが他アプリと競合したら、記録ツールの画面ボタンを使えます。
通常の数字キーやF8/F9単体は、この記録ツールが横取りしません。

記録するもの
------------
・FiveMが前面にある間の、画面中央の正方形（高さの28%）。円・数字用。
  目標60fps、実際の撮影開始/終了時刻をフレームごとに保存。fpsは保証値ではありません。
・右寄りの通知領域と、下中央の獲得アイテム領域。約6回/秒。
・数字0〜9（上段とテンキー）の押した/離した観測時刻。2ms間隔を要求して観測。
  実際のポーリング間隔も記録します。極端に短いキー入力は取り逃す可能性があります。
・一時停止、FiveMの前面状態、記録範囲、保存理由、任意の目印。

記録しないもの
--------------
・音声、マイク、全画面、他アプリが前面の間の画面やキー。
・数字以外の文字入力、パスワード、クリップボードの取得処理。
・ゲーム内のメモリ、NUI/DOM、内部通信、非表示のゲームデータ。
撮影範囲に文字やゲーム内通知が出れば、その画像には残ります。
このツールは画面上のチャット内容を識別して消すものではありません。
チャット、ログイン、個人情報の入力時は必ず一時停止してください。
通知欄の位置は添付画像を基準にしています。共有前にcontext画像を確認してください。
自動アップロードはありません。ZIPは利用者が添付したときだけ共有されます。

保存先
------
通常は「ドキュメント\FishingRecorder」。OneDrive等で同期している場合はその設定に従います。
共有用ZIPと、元データのフォルダーを両方残します。
記録は既定3分（画面で5分も選択可）、画像データ180MiBまでで自動保存します。
ZIP作成用の空き容量として500MiB以上が必要です。
「終了」後の処理中は強制終了しないでください。元データは自動削除しません。

データの読み方
--------------
ring.avi            中央のMJPEG動画。動画フレーム順にframes.csvが対応します。
frames.csv          全フレームの撮影開始/終了時刻、FiveM矩形、撮影範囲。
events.jsonl        数字キー押下/解除、フォーカス、一時停止、目印。
context/            通知・獲得領域の画像。
context.csv         context画像と同じ単調増加時計による時刻。
session.json        記録設定、形式、開始UTC時刻。
summary.json        記録枚数、最大観測間隔、入力数、終了理由。
contacts/           数字を押した直後の中央サンプル。
review.html         contactsを一覧で見るページ。ブラウザーで開けます。通信しません。

注意：AVIは名目60fpsです。フォーカス喪失や欠落フレームの時間は再生に含まれません。
秒数・入力タイミングの解析は必ずCSV/JSONLの t_ms を基準にします。
数字2は釣り竿にも追加判定にも使われ得るので、「投げた回数」とは自動分類しません。
数字を押した回数や円が消えた回数を、釣れた魚の数とは扱いません。

記録がうまくいかない場合
----------------------
中央が黒い、別の場所、0フレーム：FiveMをウィンドウ／ボーダーレス表示にして再記録。
数字入力0回：釣りで数字を押したか、FiveMが前面だったかを確認。
ゲームとツールの実行権限が違う場合、記録できないことがあります。普段の通常起動を推奨。
他アプリの通知や重ねた画面が撮影範囲を隠すと、その見た目が記録される場合があります。
録画中は他アプリを重ねず、ゲーム画面全体をモニター内に収めてください。
未知のゲーム内部状態は取得しません。撮影した範囲で分かることだけを後から分析します。
このEXEにはMicrosoftのコード署名は付いていません。セキュリティ機能を無効化しないでください。
