# AI採掘機 v9.1.10

FiveMの対応UIを検出し、採掘・石洗い・砂金取りを繰り返すWindows向け補助ツールです。**サーバー側への追加リソース導入は不要**です。既存の対応NUIを使うため、すべてのサーバーで同じ動作になる保証はありません。

> 使用するサーバーのルールと管理者の許可に従ってください。ゲームメモリ読取り、DLL/ASI注入、アンチチート回避は追加しません。

## v9.1.10の変更

石洗いの前進補正を、入力信号の送信成功だけで判断する方式から、**開始時の景色を保持し、洗浄後のずれと短いW入力の効果を実画面で確認する方式**へ変更しました。ずれがない場合は前進せず、入力が効かない・ずれが増える・照合できない場合は成功扱いにしません。基準は毎回取り直さず、累積後退を追います。

従来の固定2秒待ちと各回の強制下向きは、補正ON時には画像による静止確認へ置き換わります。ゲーム側の作業時間、クールダウン、報酬制限は変更しません。実FiveMでの速度改善量は未測定です。**この視覚補正はFiveM前面が必要**で、バックグラウンドのまま同じ補正ができるとは扱いません。

前回未配信だった自然視点のF6開始ルート記録と、作業・荷台にその場で届く配置向けの近接収納も含みます。記録モードからのキー・カメラ入力は禁止し、勝手に下を向けません。

詳細: [更新内容](docs/RELEASE_v9.1.10.md) / [使い方](docs/AI採掘機_使い方.txt) / [検証記録](docs/VALIDATION_v9.1.10.md)

## 導入と石洗い

1. アプリ内の「アップデートを確認」、または [Releases](https://github.com/kanzakideath/fivemstonefarm/releases) から `AI-Miner-v9.1.10.zip` を取得します。手動導入は書き込み可能な場所へ展開し、`AI採掘機.exe` を起動してください。既存の設定・セーブは削除しないでください。
2. 「設定」の「作業位置と視点を自動復旧」をONにして保存します。
3. 石洗いできる場所に未洗浄石を持って立ち、岩や岸など動かない目印が見える視点にします。
4. 「概要」で「石を洗う」を選び、FiveMを前面にしてF8で開始します。開始位置の基準取得と各回の補正は自動です。
5. 「ルート設定」の「石洗いの位置補正・入力と効果」で、Wの回数、合計時間、観測結果を確認できます。停止はF9です。

水面だけの構図、遮蔽、視点変更、照明変化などで景色を判定できない場合は停止します。表示するpxは縮小画像の変位であり、ゲーム内の正確なXYZ座標や移動距離ではありません。

## 対応作業

| モード | 検出表示 | 標準動作 |
|---|---|---|
| 採掘 | `鉱石を採掘する` | 進捗完了、実報酬、次の対象を確認して継続 |
| 石洗い | `石を洗う` | 進捗・報酬確認後に景色の静止とずれを測り、必要時のみ短いWで補正。石0で通知・設定済みなら補充へ |
| 砂金取り | `砂金採りトレイ` | 作業対象と視点を確認し、進捗・実報酬確認後に継続 |

「ストレージを開く」が同時表示されても、洗浄では洗浄対象だけを一度選びます。クリックや入力APIの成功を実報酬・移動成功と混同しません。補正OFFの石洗いでは位置保持を行わず、従来の待ちを残します。

開始・停止キーは変更でき、初期値はF8/F9です。徒歩・位置補正の緊急中止ではF9も使います。手動操作やフォーカス喪失時は入力を止めます。

## 車両登録と自動収納・石補充

「ルート設定」は左メニュー、概要・車両画面の案内、トレイ、Ctrl+Alt+Rから開けます。まず通常操作で自分の停車車両の荷台を一度開いて登録してください。

**同じ場所で作業と荷台に届く場合:** 「この位置で近接収納を確認（歩かない）」を使います。作業対象→登録荷台ID→閉鎖→作業対象を移動・視点変更・アイテム転送なしで確認し、成功後に「自動収納・補充をON」。徒歩ルートは不要です。

**離れた車両の場合:** 「画面ガイド付きで往復を記録」を使います。視点を整えてF6で開始し、W/A/S/Dとマウスで往路・復路を教えます。4秒以内ごとに約1秒停止して照合点を保存し、各終点でF7。元の現場から自動試走が成功したらONにします。旧下向き方式のルートは再記録が必要です。徒歩中はFiveMを前面にしてください。

石掘り・砂金取りは容量のしきい値で収納へ、石洗いは石0または容量不足で成果収納・石補充へ進みます。開始後に得たと確認できる成果だけを台帳へ記録し、登録荷台ID・品名・metadata・数量・操作結果・双方のインベントリを照合します。既存の食料や道具を全搬出しません。

補充は実際の洗浄で学習した未洗浄石だけを対象とし、荷台在庫、重量、空きスロット、作業用の余裕から量を計算します。荷台満杯・石在庫0・不明な転送結果では停止します。送信後に結果が不明な要求を盲目的に再送しません。

「直近の収納サイクル」は荷台、収納、補充、帰還、次の実報酬の確認を分けて表示し、途中段階を一周完了とは表示しません。車両位置・現場・画面設定が変わったら再記録／再試走し、再接続時も現在の接続を確認してください。任意の車両をどこまでも追跡する機能ではありません。

詳しい手順: [EXE_ONLY_ROUTES.md](docs/EXE_ONLY_ROUTES.md)

## 音声・食事・診断

完了音声は **VOICEVOX:四国めたん** の生成済みWAVをEXEに同梱しています。音声サーバーやAPIキーは不要です。クリア・甘め・OFFと、満杯／石0の区切り・一回成功ごとを選べます。セリフは「石掘りが終わったよ」「石洗いが終わったよ」「砂金取りが終わりました」です。実在声優の複製や他作品の公式音声ではありません。

自動食事はホットバースロット1が既定で、設定から切り替えます。使用前後の個数減少が確認できた場合だけ食事成功とし、確認できないまま無限に続けません。

ゲーム上のオーバーレイには手順や入力状態を表示します。画面照合時には自身のパネルを隠します。`exe-routes/wash-position-last.json` に洗浄補正の実入力時刻・計測結果、`last-cycle.json` に直近収納、各ルート `.last-run.json` に経路結果、`setup-diagnostics.log` に設定結果をローカル保存します。画面やログの自動送信はありません。

## Stone Metagame / STONEVERSE

STONEからHOME、ガチャ、図鑑、実績、プロフィールを開けます。確認済みの実作業報酬だけを一意なイベントで加算し、クリック・アニメーション開始・収納・復帰では加算しません。STONEVERSEは独立したゲーム画面です。

設定とセーブは別管理で、原子的保存、バックアップ、確認済み報酬の回復記録を使います。v9.0.2以降の既存ログ移行では確認済み記録のみを取り込み、削除済み記録や推定値は復元しません。今回の保存分岐選択では、同じ進行度でランダムな装飾数の差だけによって既定名がカスタム名より優先される問題を修正しました。

## ビルドと検証

Windows 10/11 64bit、PowerShell、Node.js20以降、.NET SDK8以降と.NET Framework参照アセンブリ、Gitを使用します。依存関係はロックファイルと固定ツールチェーンに従います。

```powershell
pwsh -File .\scripts\Build.ps1 -Version 9.1.10
pwsh -File .\scripts\Test-WashPositionDesktop.ps1
```

ビルドはWeb UI、WebView2ホスト、FiveM bridge、位置補正helper、更新helper、完成EXEの検証を行います。PR CIでは実ソースを書き換えずにビルドし、本番helperの画面キャプチャとW押下/解除を合成Windows画面で試験し、4種類の画面サイズでルートUIを操作します。

**合成画面での実Windows入力試験は、実FiveMの入力・洗浄・収納・補充の検証ではありません。** 実ゲームの長時間動作と速度改善量は未確認です。最初の数回を見届け、入力と効果の表示・次の実報酬を確認してください。詳細と試験結果は [VALIDATION_v9.1.10.md](docs/VALIDATION_v9.1.10.md) を参照してください。
