# AI採掘機 v8.0.5

FiveMの対象UIを構造的に検出し、採掘・石洗い・砂金採りを繰り返すWindows向け補助ツールです。バックグラウンド操作では、物理マウスや別アプリのフォーカスを奪わず、画面座標やモニター解像度にも依存しません。

> 使用するサーバーのルールと管理者の許可を必ず確認してください。DLL注入、プロセスメモリ読取り、アンチチート回避は行いません。

## 対応作業

| モード | 検出表示 | 標準動作 |
|---|---|---|
| 採掘 | `鉱石を採掘する` | 石の消失と再出現を確認して再実行 |
| 石洗い | `石を洗う` | 進捗UIで完了を検知し、1度だけ前進補正して次の対象を即選択 |
| 砂金採り | `砂金採りトレイ` | 約6秒周期、未検出時の境界付き補正 |

石洗いの対象が同時に複数表示された場合は、使用可能な候補を1つに絞って選択します。

開始・停止キーは変更できます。初期値は開始 `F8`、停止 `F9` です。

## 車両登録と自動収納

サーバー側へのファイル導入、車両座標、W/A/S/D・矢印キーの記録は使いません。

1. 「車両」で「車両を登録」を押します。
2. FiveMへ戻り、登録したい車両のストレージを通常どおり一度開きます。
3. アプリが `trunk` の不透明なストレージIDを検出し、PC内の設定へ保存します。
4. 採掘・石洗い・砂金採りの開始時に所持品を基準化します。
5. 現在の各アイテム重量の合計と `maxWeight` による残り重量が設定値以下、または全スロット使用になると作業を止めます。
6. 近距離で視点と短い移動を境界付き探索し、同じストレージIDの荷台だけを開きます。
7. 開始後に増えた持ち物だけを収納し、往路を逆再生して作業ボタンを再検出できた場合だけ再開します。

別車両のIDが開いた場合は何も移しません。車両が近くにない、探索範囲外へ移動した、荷台が満杯、入力復元や作業位置の再検出に失敗した場合は安全停止します。サーバー側APIを使わないため、マップ上の任意の遠距離車両を追跡する機能ではありません。

## 視点固定と自動食事

バックグラウンド作業中は、採掘・石洗い・砂金採りの各試行前に下向き視点を定期的に再適用します。物理マウスは動かしません。「設定」の「作業位置と視点を自動補正」で位置補正と一緒に切り替えられます。

接続確認・視点補正・食事判定は作業アニメーションの待ち時間内に先行して行い、次の作業ボタンが使える時刻へ余分な保守待ちを重ねないようにしています。容量は報酬反映後に確認し、速度のために満量判定を省略しません。

稼働中にFiveMを前面へ戻すと、作業種別・現在状態・操作回数・残り重量・収納回数を示すクリック透過HUDがクライアント上部に表示されます。別アプリへ切り替えると自動で隠れます。ウィンドウ表示とボーダーレス全画面に対応します。

自動食事は既定でホットバースロット `1` を使い、「設定」でオン／オフとスロット `1`～`5` を変更できます。FiveMが前面なら空腹ゲージを複数回確認し、裏画面でゲージを読めない間は開始1分後、その後8分ごとの保守的なフォールバックを使います。指定スロットへ実際に使用できる食べ物を置いてください。使用前後の同スロット個数が減った場合だけ成功として記録し、3回続けて確認できなければ食べずに採集し続けないよう安全停止します。

## 導入

1. [Releases](https://github.com/kanzakideath/fivemstonefarm/releases) から `AI-Miner-v8.0.5.zip` を取得します。
2. 書き込み可能なフォルダーへ展開します。
3. `AI採掘機.exe` を起動します。
4. 「設定」でバックグラウンド操作、キー、視点補正、自動食事・食料スロット、収納開始重量を確認します。

設定は同じフォルダーの `AI採掘機.ini` に保存され、自動更新後も維持されます。

## UI

従来のAutoHotkey標準ウィジェット画面は廃止しました。バックエンド処理は維持し、ローカルWebView2上のFramework7 iOSテーマで、概要・車両・設定・アップデートを共通のサイドバー、グループ化リスト、選択シート、スイッチ、主操作ボタンへ置き換えています。UI資産はEXEへ埋め込み、通常起動時にCDNへ接続しません。

## 安全停止と更新

FiveMのウィンドウ/PIDと対象・インベントリNUIのセッションを固定し、FiveM終了、プロセス置換、サーバー再起動・再接続相当の変化、連続した読取り失敗を検知すると入力を解放して停止します。自動再ログインは行いません。

更新先はこのリポジトリのGitHub Releasesに固定されています。製品名・URL・サイズ・SHA-256・ECDSA署名・置換後自己検証がすべて一致した場合だけ更新します。

## ソースからビルド

必要なもの:

- Windows 10 / 11（64 bit）
- PowerShell
- Node.js 20以降
- .NET SDK 8以降と .NET Framework参照アセンブリ
- Git

```powershell
pwsh -File .\scripts\Build.ps1 -Version 8.0.5
```

ビルドは依存ロック、Web UI、WebView2ホスト、FiveM bridge、更新helper、完成EXEの自己テストを実行します。
