# ソース配置

ビルドは次のファイルを使用します。

- `mining-auto.ahk`: v6.0.0のメインアプリ。採掘・石洗い・砂金採り、解像度に依存しないバックグラウンド操作、レスポンシブWindows UI、車両収納の登録・安全制御を含みます。
- `background-bridge/CdpBridge.cs`: FiveM NUIバックグラウンド操作ヘルパー
- `updater/Updater.cs`: 署名付き更新ヘルパー
- `assets/`: `FileInstall` するPNGなどの静的アセット

車両収納は、ライブ画面での初回登録が前提です。作業位置から車両後部までと、その復路の W/A/S/D 入力を別々に記録し、開いたストレージの ID と種類を保存します。実行時はインベントリの構造化スナップショットをスロット・名前・正規化メタデータ・数量ごとに基準化し、開始後に増えたアイテムだけを移します。登録車両・経路・復帰先の作業対象を確認できない場合は安全停止するため、任意経路探索、車両所有者の検出、移動済み車両の追跡には対応しません。

`Build.ps1` は `src/` を一時ステージへコピーし、C#ヘルパーを `AI採掘機_Background.exe` と `AI採掘機_Updater.exe` の名前でステージ直下へ生成してから、AutoHotkeyアプリをコンパイルします。生成されたEXEを `src/` へコミットしないでください。
