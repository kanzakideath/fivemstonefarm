# ソース配置

ビルドは次のファイルを使用します。

- `mining-auto.ahk`: v6.1.0のメインアプリ。採掘・石洗い・砂金採り、解像度に依存しないバックグラウンド操作、レスポンシブWindows UI、移動と視点を含む車両ルート登録・安全制御を含みます。
- `background-bridge/CdpBridge.cs`: FiveM NUIバックグラウンド操作ヘルパー
- `updater/Updater.cs`: 署名付き更新ヘルパー
- `assets/`: `FileInstall` するPNGなどの静的アセット

車両収納は、ライブ画面での初回登録が前提です。作業位置から車両後部までと、その復路の W/A/S/D 入力に加え、矢印キーからDevConへ送った4方向の視点入力を同じ時系列で別々に記録します。旧 `duration:mask` の下位4bitを維持し、上位4bitを視点に使うため、v6.0.1以前のルートも読み込めます。開いたストレージの ID と種類を保存し、実行時はインベントリの構造化スナップショットをスロット・名前・正規化メタデータ・数量ごとに基準化して、開始後に増えたアイテムだけを移します。登録車両・経路・復帰先の作業対象を確認できない場合は安全停止するため、任意経路探索、車両所有者の検出、移動済み車両の追跡には対応しません。

登録HUDはクリック透過の軽量なネイティブGUIで、移動・視点キー、押下状態、記録時間、対象の検出結果を表示します。到着はEnterで確定し、車両または作業ボタンを検出できないときは、その場で追加調整を記録して再確認できます。再生の中断・例外・終了時は移動と視点の全入力を解放します。

`Build.ps1` は `src/` を一時ステージへコピーし、C#ヘルパーを `AI採掘機_Background.exe` と `AI採掘機_Updater.exe` の名前でステージ直下へ生成してから、AutoHotkeyアプリをコンパイルします。生成されたEXEを `src/` へコミットしないでください。
