# AI採掘機 v9.1.20 — 石掘り・砂金取りの開始判定修正

## 修正

- 自動収納OFFの石掘り・砂金取りが、存在しない荷台ボタンを待ち続ける問題を修正しました。
- 自動収納OFFでは、作業ボタン、進捗停止、インベントリ閉鎖、同一サーバー接続を確認する専用経路で開始します。
- 自動収納ONと荷台前エンドレス石洗いでは、登録荷台との同時確認を維持します。
- 固有の荷台ラベルと一般的な「インベントリを開く」が並んだときは固有荷台を優先し、誤った複数候補判定で停止しないようにしました。
- 固有荷台がない場合は一般ラベルを1件だけfallbackとして利用し、同じ優先度の候補が複数なら操作しません。

## 更新

F9で停止してから更新してください。設定・車両登録・STONE保存データは削除不要です。複数のフォルダーにEXEがある場合、更新されるのは現在起動しているコピーだけです。タイトルと概要画面が `v9.1.20` であることを確認してください。

## 検証範囲

実DOM式を使い、石掘り・砂金取りの作業専用クリック、収納ONの荷台gate、固有荷台と一般ラベルの同時表示、一般ラベル複数時の曖昧拒否を検証します。完成EXEのvalidate/smoke、既存Farm・収納・STONE・UI・更新回帰もリリース条件です。実FiveMサーバー固有の長時間動作は実地確認が必要です。
