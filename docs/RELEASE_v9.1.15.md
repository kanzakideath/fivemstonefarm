# AI採掘機 v9.1.15 — 荷台前専用・移動なし・一時不在から自動再開

## 変わる動作

荷台前で作業とストレージを同じ立ち位置から開く使い方に限定します。通常の自動操作からW/A/S/D、前進補正、視点補正、徒歩往復を呼び出しません。古いINIや徒歩ルートが残っていても、アプリ側の移動コマンドと位置補正ヘルパー実行入口で拒否します。既存のルート画像を削除することはありません。

一時的に作業・荷台のボタンが消えたり、進捗中・所持品画面が開いていたりする場合は、終了してF8の押し直しを要求せず **「自動再開待ち」** と表示します。同じ実行世代・タスク・接続を監視し、操作可能になれば自動再開します。待機の回数上限は設けず、再確認間隔を最大5秒まで延ばし連打を避けます。

作業を開始する直前にも、作業と荷台の同時表示を再確認します。開始後の進捗、石の消費、実報酬、収納先荷台ID、数量・metadata、双方のインベントリと転送レシートを引き続き照合します。単に「待機が終わった」ことを作業や収納成功には数えません。

未洗浄石が0なら洗浄ボタンを要求せず荷台確認から補充へ進みます。荷台の石も0であり、何も取得していないと明確に確認した場合は、石が補充されるまで待ちます。出所不明の増減・送信後の結果不明・別荷台・接続変更は自動再送や自動再開の対象ではありません。

## 固定の意味と限界

止めるのは **ツールが送る移動とカメラ入力** です。ゲーム内の座標、洗浄アニメーション、他のプレイヤーや車両による物理移動を凍結する機能ではありません。ゲーム側の移動で範囲外になりボタンが戻らない場合は、待機が続きます。移動せずに範囲外から復帰できると保証しません。

F9または停止ボタンは常に手動停止です。確認できない転送を何度も繰り返して「動き続けているように見せる」変更ではありません。重大な確認不能は従来どおり停止します。

## 使い方

1. 自動操作を停止して更新します。自分のINI・STONEデータは削除しません。
2. 荷台前で作業とストレージが両方使える立ち位置・視点にします。
3. 左メニュー「荷台前の設定」で自分の荷台を登録し、「この位置で近接収納を確認（歩かない）」と自動収納・補充ONを確認します。
4. F8で開始。以後の一時不在では「自動再開待ち」から自動復帰します。徒歩記録・前進量の調整は不要です。

再接続後は新しい接続と登録荷台を確認してから開始します。接続が変わる前の未確定作業を新しい接続へ持ち込んで再実行しません。

## 診断と検証

診断ZIPに `STATIONARY_WAIT` と `STATIONARY_AUTO_RESUME` を残し、待機理由と回数を区別します。待機中に報酬台帳や転送レシートを初期化しません。F9による中止と、世代変更後の遅延結果の破棄も記録・検証します。自動送信なし。

実行結果はWindows CIとPRに記録します。単体・DOM・実際のAHK待機ループを模擬アダプターへ接続した試験は、実FiveMでの長時間プレイ成功率の証明ではありません。
