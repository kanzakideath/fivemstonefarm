## 本番ヘルパーによるWindows実入力試験

テスト用のWindowsウィンドウを前面に表示し、**本番のWashPosition.exeを変更せず起動**しました。画像取得や入力関数のモックではなく、実際の画面キャプチャとWindowsのW押下・解除イベントを通した試験です。ただし相手は合成テクスチャのテスト画面であり、FiveMではありません。

| 条件 | 観測したW押下/解除 | 結果 |
|---|---:|---|
| 開始基準を保存 | 0 / 0 | WASH_ANCHORED |
| ずれなし | 0 / 0 | WASH_STABLE、移動させない |
| 合成画面が4単位ずれている | 4 / 4、要求時間計165ms | ずれ0へ復帰を画像で確認 |
| Wに反応しないテスト画面 | 2 / 2 | FORWARD_NO_OBSERVED_EFFECTで停止 |
| Wで逆方向へ動くテスト画面 | 1 / 1 | WRONG_DIRECTION_OR_CAMERA_MOVEDで停止 |
| 開始前キャンセル | 0 / 0 | CANCELLED |

全ケースで押下と解除の数が一致し、終了後にWが押されていないこともWindows APIで確認しました。レポート: `artifacts/observed-wash/desktop-input-report.txt`。この試験は `scripts/Test-WashPositionDesktop.ps1` と読み取り専用PR CIで再実行できます。
