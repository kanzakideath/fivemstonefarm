# v9.1.13 検証項目

新規の検証は、同一の本番推定器・補正関数を使用します。

- 0、0.18、0.30、0.40、0.65、1.25画像pxの変位を分数画素として計測。
- 同じ基準のまま、0.18pxずつ後退する100回の模擬洗浄に対し残差と入力上限を確認。
- 無変位はW入力ゼロ。有効な前進後に1サンプルだけ遅れたケースで再観測を継続。
- 連続無反応2回、逆方向、キャンセルの停止、キー解除を維持。
- Windows合成ウィンドウを1物理pxずつずらし、旧プロファイルは入力しないが、荷台前プロファイルでは実W入力で戻すことを8回確認。
- 完成EXEのGUIアップデーター互換性、設定保持、既存の収納/補充/通知/画面テストを再実行。

実行結果は当該PRおよびCIの保存済みレポートに記録します。テスト項目の記載だけでPASSとは扱いません。実FiveMでの速度、微小後退、長時間連続収納・補充は未検証です。
