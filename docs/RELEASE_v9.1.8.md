# AI採掘機 v9.1.8 — EXE単独の徒歩ルート・作業別完了ボイス

## 更新内容

サーバーへの追加リソース導入なしで、教示した往路・復路をEXE内蔵の画面照合つき徒歩ヘルパーで再生する方式です。以前のサーバー連携版PR #2とは別実装です。

**初回に車両画面の「徒歩ルート・音声設定（EXEのみ）」から、作業ごとに往復を教え、「自動試走（収納しない）」を成功させる必要があります。** 荷台IDだけでは徒歩先を特定できません。

- 石掘り・砂金取り：容量しきい値→完了通知→登録往路→荷台ID照合→確認済み成果の収納→登録復路→作業対象確認→次の実報酬で再開確認。
- 石洗い：最後の未洗浄石0→完了通知→洗浄後の静止待ち→登録往路→洗浄成果収納→荷台から安全な所持上限まで石補充→登録復路→洗浄再開確認。
- 収納・補充の数量台帳、metadata、両側インベントリ照合、不確定な要求の二重送信防止を維持しています。

## 完了音声

音声：**VOICEVOX:四国めたん**。EXEに生成済みWAVを同梱し、実行時の音声サーバー・合成エンジン導入・APIキーは不要です。特定の実在声優の声の複製・模倣や、他作品の公式音声ではありません。

| 作業 | セリフ |
|---|---|
| 石掘り | 石掘りが終わったよ |
| 石洗い | 石洗いが終わったよ |
| 砂金取り | 砂金取りが終わりました |

初期音声はノーマルのクリアな女性音声です。甘め・音声OFFへ変更できます。既存の選択は保持します。既定の通知は満杯／手持ち石0の区切りです。「作業が1回成功するたび」への切替も可能です。F9中止・失敗を完了として読み上げません。

## 初回の設定

1. 通常の車両登録で停車したバン／トラックの荷台を登録します。
2. 作業モードを選び、作業可能な現場で「往復を教える」を開始します。石洗いの教示・試走には手持ち石が必要です。
3. W/A/S/Dとマウスで歩き、4秒以内ごとに立ち止まって約1秒待ち、照合点を作ります。荷台前の終点でF7、復路は同じ現場へ戻ってF7です。
4. 元の現場から自動試走を行います。往路・登録荷台・復路・作業対象の確認が成功した経路だけ有効になります。
5. 自動収納を有効にして作業を開始します。

詳細は同梱の `EXE_ONLY_ROUTES.md` を参照してください。

## 動作条件・制約

徒歩中はFiveMを前面で使用します。他アプリへの切替、F9、手動介入で停止します。車両位置・作業現場・接続・画面設定が変わった場合は再教示／試走が必要です。天候・照明・遮蔽物によって画面照合できない場合も停止します。任意の車両をどんな状況でも自動追跡する機能ではなく、実機での全条件の到達保証はありません。

この更新にサーバー側への新規導入、ゲームメモリ読取り、DLL注入、アンチチート回避は含みません。既存の対応NUIを使用します。利用サーバーのルールと許可に従ってください。
