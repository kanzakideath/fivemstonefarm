# AI採掘機 v9.1.9 — 見えるルート設定・画面ガイド

## 修正

v9.1.8のルート設定ボタンは、白文字に対して背景を描画する子要素がなく、透明背景の上で見つけにくい状態でした。専用の背景色を持つ案内カードと、独立した「ルート設定」画面に変更しています。

入口は「概要」の開始ボタンの上、「車両」画面の上部、左メニューの「ルート設定」、トレイメニューです。Ctrl+Alt+Rでも開けます。狭いウィンドウのメニューは横スクロールで全項目を表示します。

## 設定手順

1. 「ルート設定」を開き、石掘り／石洗い／砂金取りを選択します。
2. 停車した自分の荷台を「車両登録を開始」で登録します。
3. 作業できる現場から「画面ガイド付きで往復を記録」を開始します。
4. ゲーム画面の案内を見ながら荷台まで歩き、止まってF7。案内が復路に変わったら同じ現場まで戻り、止まってF7です。
5. 元の現場から「自動試走を開始（収納なし）」で往復を確認します。
6. 成功後に「自動収納・補充をON」にして、作業画面へ戻ります。

記録中は4秒以内ごとに立ち止まってください。保存済み照合点数、区間の時間、F6（照合点）・F7（片道終了）・F9（中止）をオーバーレイに表示します。荷台IDや帰還先の確認中にも別の案内が出ます。石洗いの記録・試走は未洗浄石を持って行ってください。

## 表示の意味

荷台登録・往復記録・保存済み試走・自動収納ONを別々に表示します。「前回の試走記録あり」は現在位置や現在接続の保証ではありません。実行時には従来どおり接続・登録ID・ルートファイルの一致を再確認します。未登録や未試走の操作は画面で無効化し、成功表示を先に付けません。

オーバーレイは案内用で、ゲームにフォーカスを奪わせない方式です。景色の撮影時には自身のパネルを隠し、案内パネルそのものを目印に誤認しないようにしています。表示する矢印は手順の説明であり、取得できていないワールド座標や実際の経路を装うものではありません。

## 維持する条件

サーバー側への新しいリソース導入は不要です。EXE内蔵の教示・再生方式を維持し、ゲームメモリ読取り・DLL注入・アンチチート回避は追加していません。収納台帳、荷台ID照合、補充確認、二重送信防止、F9中止も維持します。

記録・試走・徒歩中はFiveMを前面にしてください。車両位置・作業現場・接続・画面設定が変わった場合は再記録／再試走が必要です。照明・遮蔽物などで景色が合わなければ停止します。実FiveMで全条件の到達を保証する更新ではありません。

既存の設定とセーブは保持し、音声はVOICEVOX:四国めたんの既存3セリフを維持します。

## 検証の区別

画面幅ごとのブラウザー操作試験、Windowsコンパイル、完成EXEの自己テスト／起動検証と、実ゲームでの徒歩・収納・補充は別の試験です。この開発環境から実FiveMでの往復試験は行っていません。各現場で最初に収納なしの試走を行ってください。

## 収納の観測記録と再試走

直近サイクルは移動開始・荷台ID確認・収納確認・補充確認・帰還確認・次の実報酬確認を区別します。最後の実報酬を確認するまでは一周完了ではありません。`exe-routes/last-cycle.json` は観測記録であり、再実行の指令ではありません。徒歩の失敗区間・一致度・経過時間は各ルートの `.last-run.json` へローカル保存します。画面やログの自動送信はありません。

ルートの文字列照合は大文字小文字まで一致させます。再接続後も保存済みの道自体が一致していれば、往復の自動試走で今回の接続を再確認できます。試走に成功するまでは実行時の接続ガードを解除しません。

追加の300回の計画反復および3モード各100回の完了状態検証は模擬・ロジック試験であり、実FiveMでの300往復成功を意味しません。全地形・任意の車両位置での自動移動を保証するものではありません。
