# AI採掘機 v9.1.13 — 荷台前の微小後退補正・共有できる診断ログ

## 荷台前の石洗い

確認済みの近接収納・石洗いに限り、毎回の実報酬確認後に `wash-maintain` を使用します。一般経路の0.65pxではなく0.20pxの許容範囲と、画素間の移動を直接当てはめる計算で小さなずれを測定します。このpxは256×144に縮小した画像の値で、ゲーム内の距離やXYZ座標ではありません。開始位置は固定し、毎回後退した位置へ基準を更新しません。

短いW入力の後に画面を再確認します。効果のあった入力の直後に1回変化が小さかっただけで停止する条件を、連続して効果を確認できない場合の停止へ修正しました。最大8入力・合計360ms・1入力80ms以下・無反応2回・逆方向の悪化で停止する上限は維持します。誤方向・F9・手動操作・フォーカス喪失・キー解除失敗は続行しません。ずれがないときに強制前進して荷台へ押し付ける方式ではありません。

「両方のボタンが出る」は収納の操作範囲の確認であり、位置が戻った証明ではありません。前進補正を先に行い、限定した不確定結果だけ既存の操作範囲確認へ進みます。収納・石補充では登録荷台ID、数量、metadata、両インベントリ、転送結果を引き続き確認します。

オーバーレイに前進補正ON/OFF、静止確認中のW未送信、送信後の回数と時間を表示します。位置補正OFFを勝手にONにしません。`WASH_RECOVERY_TICK` と `WASH_CORRECTION_PROFILE`、`exe-routes/wash-position-last.json` にプロファイルと許容値を記録します。

## 診断ログ・診断ZIP

今回から、起動セッション、UTC時刻、単調時刻、連番、実行世代、タスク、作業、FSM状態、前進補正/収納ON・OFF、停止理由、W入力の回数・時間・観測結果をローカルJSONLへ記録します。稼働中は5秒ごとの状態も残します。従来の報酬復元用ログは変更せず、別の履歴を保持するため作業の再開始で消えません。2MiB×5ファイル（最後の1行分の超過を除く）で古いものから置き換えます。

**「設定」→「不具合の記録・診断ZIP」** を開きます。発生時に **「今の不具合に目印を付ける」**、F9で停止後に **「診断ZIPを保存」** を押してください。ルート設定・アップデート画面からも開けます。画面不調時はトレイメニューから保存できます。

ZIPにはUTF-8のREAD-ME、直近のJSONL、最後のエラー候補と目印、許可した補正/ルート結果、実行EXEのハッシュを含めます。生のINI、セーブ、画像、音声、チャット、ルート基準画像は対象外です。パス・メール・接続識別子等は可能な範囲で除外しますが、未知の自由文の完全匿名化は保証しません。共有前に内容を確認してください。**外部への自動送信はありません。保存したZIPをこのチャットへ添付すると調査できます。** PC内のログをチャットから直接読む機能ではありません。

ログを書けない場合は画面に失敗回数を表示し、操作の成功扱いや再送には変換しません。強制終了前の未実行コードまで記録できる保証はありません。取得できないファイルや途中書込みの行はmanifestに記録します。詳細は `docs/DIAGNOSTICS.md` です。

## 更新後の使用

F9で停止してアップデートしてください。「設定」の「作業位置と視点を自動復旧」をON、自動収納をONにして、荷台前の「この位置で近接収納を確認（歩かない）」を確認します。確認済み近接設定では徒歩ルート不要です。未洗浄石を持ち、岩・岸など静止した景色を含む視点で、FiveMを前面にしてF8で開始します。

手動更新は現在のフォルダーをバックアップし、ZIP内のEXEだけを置き換えてください。自分のINIを配布テンプレートで上書きしないでください。

## 検証の区別

分数画素、100回の累積微小後退、無変位・無反応・誤方向・キャンセルのコード試験と、Windows実画面の1px移動に対して本番ヘルパーがW押下・解除を送る連続試験を行っています。診断のローテーション・書込失敗、ZIPの許可リスト・秘密値除外・壊れた行・上書き拒否、4画面幅の表示と操作、完成EXEのコンソールなし更新検査も検証対象です。

これらは合成画面やWindows上の検証であり、実FiveMのカメラ追従、入力受付、長時間収納・補充成功率の測定ではありません。最初の数回と最初の補充は見届けてください。サーバー側導入、メモリ読み取り、アンチチート回避は追加しません。音声、二重転送防止、v9.1.11の更新検査修正も維持しています。
