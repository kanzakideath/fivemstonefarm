# AI採掘機 v9.1.18 — 高速石洗いの独立開始と安全なバージョン選択

「最速石洗い」を設定画面のスイッチから外し、概要画面の通常開始ボタン直下に「高速石洗いを開始」を独立して配置しました。押すと石洗いへ切り替えて高速経路で開始します。高速状態はその1回の稼働だけに限定され、F9で停止した後や通常の開始ボタン／F8から次に開始したときへ持ち越しません。自動収納・食事など既存設定は変更しません。

高速石洗い中は、洗浄を続けられる通常サイクルで定期的な容量確認を別途開始しません。直前の確認済み所持品と各洗浄の実差分で容量・未洗浄石を追跡し、容量不足または未洗浄石0を確認したときだけ、従来の検証付き収納・補充経路へ移ります。結果が未確認のまま次の洗浄を送ることはありません。

アップデート画面に、インストール可能な公開版を選ぶチェック式一覧を追加しました。手入力欄や任意URLは使いません。v9.1.18では、署名とmanifestを検証できたv9.1.15以降の安定版だけを表示し、選択後の確認画面を経て切り替えます。適用直前にも選択版のECDSA署名、製品・チャンネル・バージョン、SHA-256を再確認します。

安全上、v9.1.14以前は選択肢に表示しません。v9.1.16には高速石洗い中も定期容量確認へ入る既知の問題があり、v9.1.15には高速石洗い機能がありません。旧版へ戻した後、その旧版には新しい一覧UIがないため、別の版へ移る場合は旧版の「アップデートを確認」で最新版へ戻してから選び直してください。設定、STONE保存データ、実績を削除する処理は追加していません。

検証は、Web UIの通常開始直下の配置・設定画面からの削除・キーボード選択・確認ダイアログ・IPC許可リスト、実行単位の高速状態、Updaterの不正バージョン拒否、公開済み署名manifestの一覧取得と指定版ステージング、完成EXEのvalidate／smoke-testを対象にします。実FiveMサーバー上の長時間運転はこのリリース作業環境では未検証です。
