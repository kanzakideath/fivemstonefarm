# AI採掘機 v9.1.12 — 荷台前の石洗いを操作可否で続行

## 対象

前進補正できているのに `FORWARD_NO_OBSERVED_EFFECT` で止まるケースに対応します。W入力と画像補正の処理・入力時間上限は変更しません。

近接モードで確認済みの同じ作業・登録荷台・接続に限り、画像判定だけが不確定なときは、同じNUIフレームから洗浄とストレージの両方の操作項目を読み直します。240ms以上にわたる3回の同期した組で利用可能性を確認し、前後の接続IDと現在の実行世代・タスクも確認します。操作可能なら追加前進せず次の洗浄へ進みます。画面には「荷台前の操作範囲を確認」と表示し、画像の完全一致や移動成功を偽って表示しません。

手持ち石0を直前の実報酬のインベントリで確認済みの場合は、消えた「石を洗う」を要求しません。ストレージ操作だけを確認し、既存の収納・石補充へ進みます。その段階で荷台ID・数量・metadata・両側のインベントリ・転送結果を照合します。転送結果が不明なときの再送防止、在庫切れ・荷台満杯時の停止は維持します。

キャンセル、手動操作、フォーカス喪失、接続変更、キー解除失敗、逆方向への悪化、未知の結果をこの続行条件に混ぜません。対象が隠れた・無効・複数で曖昧な場合も続行を許可しません。次の実際の洗浄完了とインベントリ変化は既存処理で別途確認します。

## 荷台前で使う

1. F9で停止して更新し、登録済み車両と自動収納ONを確認します。
2. 未洗浄石を持ち、「石を洗う」と「ストレージを開く」が両方使える荷台前でFiveMを前面にして開始してください。
3. 徒歩ルートが未作成の石洗いは、作業→登録した荷台ID→作業を実確認して、成功時だけ近接設定を保存します。確認でアイテムは移動せず、収納OFFを勝手にONにしません。
4. 既存の徒歩ルートは自動で上書きしません。徒歩から近接に切り替える場合は「ルート設定」→「この位置で近接収納を確認（歩かない）」を使用してください。

画像補正の結果は `exe-routes/wash-position-last.json`、画像判定とは別の続行判断は `exe-routes/wash-nearby-last.json` に保存します。画像判定の失敗記録を成功へ書き換えません。自動アップロードはありません。

この変更はゲームのXYZ座標の取得やサーバー側への追加導入をしません。更新検査のコンソールなし起動・設定分離の修正も維持しています。実際のFiveMでの長時間洗浄・収納・補充は開発環境からは検証できていないため、最初の数回と最初の補充は見届けてください。
