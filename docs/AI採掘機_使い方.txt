AI採掘機 v6.1.0 使い方
========================

対応環境
--------
- Windows 10 / 11（64 bit）
- FiveM
- 画面に日本語の対象ボタンが表示される環境

v6.1.0 の特徴
--------------
- 軽量なバックグラウンド操作で、物理マウスを動かさずに動作します。
- 対象ボタンとインベントリは構造的に扱うため、操作は画面解像度に依存しません。
- iOS風のレスポンシブなWindows UIで、採掘・車両・設定・更新を切り替えられます。
- 設定・ナビゲーションなどのボタンを、装飾面に遮られず確実にクリックできます。
- 作業モードは「鉱石を採掘する」「石を洗う」「砂金採りトレイ」の3種類です。
- 車両登録ではW/A/S/Dの移動と矢印キーの視点を同時に記録し、裏画面でも再生します。
- 登録HUDに移動・視点キー、押下状態、記録時間、ボタン検出結果を表示します。

最初の準備
----------
1. Releaseの「AI-Miner-v6.1.0.zip」を、書き込み可能なフォルダーへ展開します。
2. 「AI採掘機.exe」と「AI採掘機.ini」は同じフォルダーに置きます。
3. AI採掘機.exe を起動します。Windowsの警告が出た場合は、配布元とSHA-256を確認してから実行してください。
4. 使用するFiveMサーバーのルールで、自動操作が許可されていることを確認してください。

基本操作
--------
1. ゲーム内で対象の石または作業場所の前に立ちます。
2. AI採掘機で作業を選びます。
   - 鉱石を採掘する: 石の出現を検知して採掘します。
   - 石を洗う: 約9秒周期で洗い、少しずつ後退する動きを前進補正します。
   - 砂金採りトレイ: 約6秒周期で砂金採りを繰り返し、位置ずれも安全な範囲で自動補正します。
3. 「開始」を押すか F8 を押します。
4. 終了するときは「停止」を押すか F9 を押します。

バックグラウンド動作
----------------------
- 「バックグラウンド動作」を有効にすると、物理マウスを動かさずFiveM内の対象ボタンを探して押します。
- ほかのアプリを操作中でも、そのマウスやキーボード入力を奪いません。
- 石洗いと砂金採りはバックグラウンド動作を有効にして使用します。
- FiveM側のNUIデバッグ接続を利用できない状態では開始できません。アプリに表示される診断内容を確認してください。
- 砂金採りボタンを12秒間連続で検出できない場合は、前後・左右を小さく探る最大6段階の位置補正を行います。各段階の直後にボタンを再確認し、再検出すると補正状態は自動でリセットされます。
- 最大6段階の範囲でも見つからない場合は、それ以上移動せず手動調整を待ちます。キャラクターの向きや立ち位置が大きく変わった場合は、停止して位置を調整してから再開してください。

車両ストレージの登録と自動収納
--------------------------------
車両収納は、所持品の空き容量が少なくなったときに、登録した車両のストレージへ採集品を置いて作業位置に戻る機能です。最初に使うときは、実際にFiveMを起動した状態で車両とルートを登録してください。設定ファイルを手で書き換えて登録を作ることはできません。

登録前の条件:
- 「設定」でバックグラウンド動作をオンにします。
- 作業モードを選び、実際にその作業対象の前に立ちます。
- 車両を作業場所から移動しない位置に駐車し、作業場所から車両後部までの通路を空けます。
- 登録から自動収納まで、車両を動かさず、同じストレージを利用できる状態にします。

登録手順:
1. 「車両」画面で表示名を必要に応じて入力し、「車両とルートを登録」を押します。
2. FiveM上の登録オーバーレイで 1/4 の作業場所確認が終わるまで待ちます。現在のモードの作業ボタンが見つからなければ、その位置では登録できません。
3. 2/4 の「開始待ち」で全キーを離してEnterを押します。「記録中」に変わったら、W/A/S/Dで車両後部まで歩きながら、矢印キーで視点を調整します。HUD上では押しているキーが青色になります。物理マウスは動かさないでください。
4. 車両後部へ着き、ストレージが見える向きになったら、すべてのキーを離してEnterを押します。無操作時間による勝手な終了はありません。
5. 3/4 で「ストレージを開く」を自動確認します。見つからない場合は、登録を最初からやり直さず、W/A/S/Dと矢印キーで立ち位置・視点を微調整してEnterを押すと再確認します。最大8回まで調整できます。
6. 4/4 では同じ操作で元の作業位置へ戻り、作業対象が見える視点まで記録してEnterを押します。作業ボタンが見つからない場合もその場で追加調整できます。
7. 元の作業ボタンを再検出すると、保存前の往復テストを開始します。記録した往路で同じ車両ストレージを開けること、復路で元の作業ボタンへ戻れることを自動確認し、すべて成功した場合だけ登録を保存します。テスト中は操作せず待ってください。
8. Escでいつでも登録を中止でき、中止時は移動・視点入力をすべて解放します。別画面へ移ると登録を破棄せず一時停止し、矢印キーとEnterも別アプリでは通常どおり使えます。キーを離してFiveMへ戻ると再開します。

登録経路を同じ速度で再現するため、登録中のShift・Ctrl・SpaceはFiveMへ送りません。走る・しゃがむ・ジャンプを使わず、W/A/S/Dと矢印キーだけで登録してください。

v6.0.1以前の登録について:
- 古いルートは削除されず、そのまま読み込めます。ただし視点操作は含まれません。
- 「車両」画面に「旧ルートは視点なし」と表示された場合は、v6.1.0で登録し直してください。

自動収納中の動き:
- アプリはインベントリの重量、最大重量、使用スロット数を構造化データから確認します。画像上の容量ゲージの見た目だけで判断しません。
- 容量が不足すると、登録済みの往路と視点操作を一緒にバックグラウンド再生して車両へ移動します。物理カーソルや別アプリのマウス操作は動かしません。
- 車両のストレージを開いた後、登録時のストレージIDと種類の両方が完全に一致するか確認します。一致しないストレージには何も移しません。
- 開始時のインベントリをスロット・名前・メタデータ・数量ごとに基準化し、開始後に数量が増えたアイテムだけを収納します。開始前から持っていた工具、食料、同名でも状態の異なる品は移さず保護します。
- 収納後は登録済みの復路を再生し、元の作業ボタンを確認できた場合だけ自動で作業を再開します。

制限と安全停止:
- この機能は任意の目的地への経路探索、車両の所有者判定、別の場所へ移動された車両の発見には対応していません。
- 車両を動かした、通路に障害物や他プレイヤーがいる、開始時の立ち位置・視点が登録時と大きく違うなど、登録した相対入力を再現できない場合は使用しないでください。ルートを登録し直してください。
- インベントリ情報を読めない状態が続く、開始前の持ち物だけで容量が不足している、車両に到達できない、ストレージIDまたは種類が一致しない、収納できない、作業場所に戻れない、または復帰後の作業ボタンを確認できない場合は安全停止します。
- 停止後はFiveMの位置と車両を確認し、必要なら手動で戻してから再登録または再開してください。

キーの変更
----------
- アプリの設定画面で開始キーと停止キーを変更できます。
- 設定は AI採掘機.ini の [Controls] に保存されます。
- 開始と停止には別のキーを設定してください。必ず、すぐ押せる停止キーを用意してください。

自動更新
--------
- 初期設定では起動後に更新を確認します。
- 更新ファイルはSHA-256とECDSA P-256署名の両方を検証してから置き換えます。
- AI採掘機.ini は更新時にも保持されます。
- 署名が正しくない更新は適用されません。署名エラーが出た場合は実行せず、公式Releaseを確認してください。
- v5.1以前から初めて更新機能を使う場合は、v5.2.0を一度手動で導入してから、署名付き更新でv6.1.0以降へ更新してください。

うまく動かないとき
------------------
- 対象ボタンの文字が「鉱石を採掘する」「石を洗う」「砂金採りトレイ」のいずれかになっているか確認します。
- FiveMを1つだけ起動し、対象の前に立ち直して再開します。
- 砂金採りが「手動調整待ち」になった場合は、対象ボタンが再び表示される位置へ手動で戻してください。アプリは範囲外へ歩き続けません。
- 車両収納が停止した場合は、車両が登録位置にあり、往復経路が空いていて、同じストレージを開けるか確認します。旧ルート表示がある場合や視点が合わない場合は、矢印キー対応のルートとして登録し直します。
- 停止キーを押してから、AI採掘機を再起動します。
- サーバー側UIが変更された直後は、対応版が公開されるまで検知できない場合があります。
