AI採掘機 v8.0.5 使い方
========================

重要
----
- 使用するFiveMサーバーのルールと管理者の許可を確認してください。
- サーバー側へのresource導入、DLL/ASI導入、メモリ読取りは不要です。
- 車両の自動探索は作業場所の近距離だけです。遠距離の車両追跡や瞬間移動はしません。

準備
----
1. AI-Miner-v8.0.5.zipを任意の書き込み可能なフォルダーへ展開します。
2. AI採掘機.exeを起動します。
3. 「設定」で開始・停止キー、バックグラウンド操作、視点補正、自動食事・食料スロット、残り重量を確認します。

作業
----
1. 作業場所の前に立ち、作業ボタンが出る方向を向きます。
2. 「概要」で作業を選びます。
   - 鉱石を採掘する: 石の再出現を検知します。
   - 石を洗う: 進捗UIで完了を検知し、完了後に1度だけ前進補正して次の使用可能な対象をすぐ選びます。同時に複数表示された場合も1つに絞ります。
   - 砂金採りトレイ: 約6秒周期で、未検出時に小さく位置補正します。
3. 「自動操作を開始」またはF8を押します。
4. 終了は同じボタンまたはF9です。

車両登録
--------
1. FiveMで登録したい車両のストレージを開ける位置に立ちます。
2. AI採掘機の「車両」で「車両を登録」を押します。
3. 「登録する車両のストレージを開いてください」と表示されたらFiveMへ戻ります。
4. 通常の操作で、その車両の荷台・トランクを一度開きます。
5. `trunk` を検出すると自動で登録完了し、インベントリを閉じてアプリへ戻ります。

登録待ちは75秒で終了します。F9でも中止できます。開始前から開いていたストレージは誤登録防止のためいったん閉じます。保存に失敗した場合は以前の登録を残します。登録は採掘・石洗い・砂金採りで共通です。

自動収納
--------
- 残り重量 = 最大重量 - 現在重量です。
- 現在重量は、閉じたインベントリでも更新される各アイテム重量を合計して判定します。
- 残り重量が設定値以下、または全スロット使用になると、新しい作業を止めます。
- 開始前から持っていた品を保護し、開始後に増えた数量だけを移します。
- 近くを短く探索し、登録時と同じストレージIDを開けた場合だけ収納します。
- 別の荷台を開いた場合は何も移さず閉じます。
- 収納後は探索の移動と視点を戻し、元の作業ボタンを確認できた場合だけ再開します。

車両は作業場所の近くで、荷台へ徒歩で近づける位置に停めてください。車両が探索範囲外、障害物で移動不能、荷台満杯、作業位置へ戻れない場合は安全停止します。

バックグラウンド操作
--------------------
- FiveM内部の対象UIを使うため、モニター解像度や絶対マウス座標には依存しません。
- 物理マウスと別アプリのフォーカスを奪いません。
- 接続確認と視点補正は作業の待ち時間内に先行し、次の操作前の余分な待ちを減らします。容量確認は報酬反映後に行います。
- FiveMのPIDやNUIセッションが変わると入力を解放して停止します。
- FiveMが前面の間は、上部のクリック透過HUDへ作業状態・操作回数・残り重量・収納回数を表示します。別アプリでは自動で隠れます。
- HUDはウィンドウ表示とボーダーレス全画面に対応します。排他フルスクリーンで見えない場合はFiveMをボーダーレスへ変更してください。

視点固定と自動食事
------------------
- 採掘・石洗い・砂金採りの各試行前に、下向き視点を定期的に再適用します。
- 「設定」の「作業位置と視点を自動補正」で位置補正と一緒に切り替えます。
- 自動食事は既定でホットバースロット1を使います。「設定」でオン／オフとスロット1～5を変更できます。
- 指定スロットへ実際に使用できる食べ物を置いてください。
- FiveMが前面なら空腹ゲージを複数回確認します。裏画面ではゲージを読めないため、開始1分後、その後8分ごとに食事を試します。
- 使用前後で指定スロットの個数が減った場合だけ食事成功として数えます。3回続けて確認できなければ安全停止します。

設定と更新
----------
- 開始/停止キー、バックグラウンド操作、実行中に隠す、補正、自動食事・食料スロット、自動更新、収納開始重量を変更できます。
- 登録IDやStorageTypeは手編集しないでください。
- 更新は固定GitHub Releaseの署名、URL、サイズ、SHA-256、置換後検証がすべて成功した場合だけ適用します。
- AI採掘機.iniは更新後も保持されます。

うまく動かないとき
------------------
- 登録できない: 登録開始後に車両の荷台を実際に開き、右側がtrunkインベントリになっているか確認します。
- 収納しない: 車両を作業場所へ近づけ、キャラクターから荷台へ歩ける向きで停めます。
- 別車両を検出: 登録ID不一致なので安全に無視されます。登録車両を近づけます。
- 容量判定: 全マスではなく残り重量が主条件です。「設定」のg値を確認します。
- 再起動・切断: ログインと作業位置を手動確認してから再開します。

本ソフトウェアは無保証です。停止キーはいつでも押せるキーに設定してください。
