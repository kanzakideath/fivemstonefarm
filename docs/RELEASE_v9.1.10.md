# AI採掘機 v9.1.10 — 勝手な下向き補正の廃止・近接収納

## 修正内容

v9.1.9のルート記録開始と照合点保存にあった、強制的な下向きマウス入力を削除します。記録モードからのキー・カメラ入力送信を禁止し、各片道の準備画面で視点を整えて立ち止まり、F6を押すと記録を開始します。景色の特徴が不足する場合は理由を表示し、手動で向きを変えて再度F6を押すまで待ちます。

記録中の画面更新を入力記録より低頻度にし、何も操作していない時間の描画遅延だけで記録失敗にしないようにしました。移動中の大きな遅延は不正確に続けず停止します。時間区間へ割り当てるキー状態も修正しました。

古い下向き補正方式の徒歩ルートは自然視点方式で再記録が必要です。徒歩記録では4秒以内ごとに立ち止まり、片道終了はF7、中止はF9です。再生時の限定的な視点探索はありますが、記録中に勝手な下向き補正は行いません。

## 作業と荷台のボタンが同じ場所で出る場合

1. ルート設定で作業モードと停車した自分のバン／トラックの荷台を登録します。
2. ゲーム内で作業ボタンと登録荷台のボタンが両方出る位置・視点にします。石洗いは未洗浄石を用意してください。
3. 「この位置で近接収納を確認（歩かない）」を押します。
4. 移動・カメラ変更なしで、作業ボタン→登録荷台ID→荷台を閉じる→作業ボタンを確認します。この設定確認でアイテムは移しません。
5. 確認済みになったら「自動収納・補充をON」にします。

この近接モードでは徒歩ルート不要です。石掘り・砂金取りは容量のしきい値、石洗いは石0または容量のしきい値で、毎回登録荷台IDと収納・補充結果を確認します。届かない荷台へ勝手に移動しません。遠い車両には徒歩ルートを記録してください。近接と徒歩は作業ごとに選択できます。

収納・補充の数量、metadata、両インベントリ、操作結果の照合、不確定要求の二重送信防止は維持します。荷台満杯・未洗浄石在庫0・結果不明では停止します。

## 診断と限界

設定終了時は同じアプリのルート設定画面へ戻り、理由を表示します。設定処理からアプリを再起動する操作は行いません。exe-routes/setup-diagnostics.logに設定結果、各記録の.last-run.jsonに子処理の結果を残します。画面やログの自動送信はありません。本当にFiveMやEXEプロセスが異常終了している場合には、別途そのエラー記録が必要です。

記録するのは画面サイズ、景色の照合点、W/A/S/Dの時間、マウス相対移動量です。GTAワールド座標を取得したと偽りません。サーバーへの追加導入・ゲームメモリ読取り・DLL注入・アンチチート回避は追加しません。既存の対応NUIを使うため、すべてのサーバーのUIへ対応する保証はありません。

CIで検証する範囲はコンパイル・論理・画面操作です。実FiveM上の収納・補充・往復成功とは区別します。最初の一周は見届け、次の実報酬確認まで進むことを確認してください。

作業別音声は従来のVOICEVOX:四国めたんを維持します。「石掘りが終わったよ」「石洗いが終わったよ」「砂金取りが終わりました」です。
