# EXEだけで徒歩収納・石補充を設定する

## v9.1.9の入口

左メニューの **ルート設定** を開いてください。概要画面の開始ボタン上、車両画面上部の青い案内カードからも開けます。トレイメニューの「自動収納のルート設定」、Ctrl+Alt+Rも使用できます。作業中はF9で止めてから設定してください。

この方式にサーバー側への追加リソース導入は不要です。EXE内蔵の教示・画面照合付き徒歩再生と、既存の対応NUIを使用します。ゲームメモリの読取り、DLL注入、アンチチート回避は追加しません。利用サーバーの自動操作ルールに従ってください。

## 初回の設定

1. ルート設定で **石掘り・石洗い・砂金取り** のどれを設定するか選びます。道は作業ごとに別保存です。
2. **車両登録を開始** から、停車した自分のバン／トラックの荷台を一度開いて登録します。
3. 作業可能な現場に立ち、**画面ガイド付きで往復を記録** を押します。石洗いの記録・試走では手持ちに未洗浄石を用意してください。
4. 画面上のカウントダウン後、W/A/S/Dとマウスだけで荷台まで歩きます。ダッシュ・ジャンプ・乗車・UI操作は記録しません。
5. **4秒以内ごとに一度立ち止まり、約1秒待ってください。** 景色の照合点を保存します。撮影・視点補正中は動かないでください。オーバーレイの区間時間と保存済み照合点数を確認できます。
6. 荷台の前で止まって **F7**。荷台IDの確認後、画面の案内が復路に切り替わります。同じ作業現場へ戻り、止まってF7です。途中の中止はF9です。
7. 元の現場から **自動試走を開始（収納なし）** を実行します。往路、登録荷台、復路、作業ボタンを確認します。試走ではアイテムを移しません。
8. 試走に成功したら **自動収納・補充をON**。作業画面に戻って開始します。

画面の4段階は「荷台登録」「往復記録」「保存済み試走」「自動収納ON」です。ボタンは前提がそろうまで無効です。荷台IDだけを登録しても、離れた車両までの道は分かりません。

## 通常の動作

**石掘り・砂金取り:** 容量のしきい値 → 完了通知 → 往路を徒歩再生 → 登録荷台ID確認 → 確定した作業成果を収納 → 収納結果確認 → 復路 → 作業対象確認 → 次の実報酬で再開確認。

**石洗い:** 手持ちの未洗浄石0、または容量のしきい値 → 完了通知 → 洗浄後の静止待ち → 往路 → 洗浄成果の収納 → 未洗浄石の補充 → 復路 → 洗浄再開確認。

補充量は荷台の在庫、重量、空きスロット、次の報酬用の余裕から決めます。必要な食料や道具など、今回の作業成果と確認できないものを勝手に収納しません。荷台満杯、石在庫0、結果不明の転送要求では安全停止します。未洗浄石の種類は実際の洗浄で学習し、架空のアイテムIDは使いません。

## 完了と停止の見分け方

ルート画面の **直近の収納サイクル** には、移動開始、荷台確認、収納確認、石補充確認、帰還確認、次の実報酬確認を別々に表示します。途中の確認だけで一周完了とは表示しません。

徒歩のキー送信成功や画像一致だけでは収納成功と扱いません。荷台ID、数量台帳、metadata、操作レシートと双方のインベントリの確認を維持します。送信後に結果が不明な転送を盲目的に再送しません。

## 再接続・位置変更

徒歩中はFiveMを前面にします。他アプリへの切替、手動介入、F9で停止します。車両の停車位置・作業現場・画面サイズ・カメラ設定が変わった場合は再記録／再試走が必要です。

同じ道と登録荷台が保持されている再接続後は、まず自動試走を行えます。試走で今回の接続と両方の終点を確認できた場合に限り、実行用の接続情報を更新します。古い試走記録をそのまま現接続の証拠として信用しません。

## 完了ボイス

音声は **VOICEVOX:四国めたん**。生成済みWAVをEXEに内蔵し、音声サーバー・APIキーは不要です。ルート画面の音声設定から、クリア、甘め、OFFを選べます。

| 作業 | セリフ |
|---|---|
| 石掘り | 石掘りが終わったよ |
| 石洗い | 石洗いが終わったよ |
| 砂金取り | 砂金取りが終わりました |

既定は満杯／石0の区切りです。1回成功するたびにも変更できます。特定の実在声優の複製・公式音声ではありません。利用・再配布は同梱のVOICE-CREDITS.txtとvoice-manifest.jsonの規約・クレジットを引き継いでください。

## 診断と限界

Saved Games内のアプリデータ配下 `exe-routes/last-cycle.json` に直近サイクルの観測記録、各ルートの `.last-run.json` に失敗区間・一致度・経過時間・入力解除状態を保存します。これらは診断記録であり、再実行指令ではありません。ログや画面の自動送信はありません。

照明・天候・遮蔽物・似通った地形・入力遅延によって照合できない場合は停止します。未確認区間の繰り返し再生、見えない車両の追跡、任意地形での到達保証はしません。

ビルド、合成画像・模擬制御試験、画面操作試験は実FiveMの往復検証とは別です。各現場で初回の試走と、実際の収納・補充・再開結果を確認してください。
