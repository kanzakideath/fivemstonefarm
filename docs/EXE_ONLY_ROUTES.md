# EXEだけで徒歩収納・石補充 / キャラクター完了音声

## 対象と前提

この修正はサーバー側にファイルを入れません。`ai_miner_companion`、サーバー座標API、DLL注入、プロセスメモリ読取り、アンチチート回避を使いません。荷台の登録・収納・補充は従来の対応NUIを使用し、徒歩部分をEXE内蔵の画面照合つき教示・再生へ置き換えます。利用サーバーの自動操作ルールに従ってください。

**車両IDだけから離れた車両の座標を復元する機能ではありません。最初に同じ作業場所と停車車両の往路・復路を実際に歩いて教え、自動試走に成功する必要があります。**

移動時はEXEがFiveMを前面にします。この同意は記録開始ダイアログに表示します。他アプリへ切替・F9・ユーザーの手動操作があれば入力を解除して停止します。現在の画面キャプチャ方式では、最小化・他ウィンドウに隠れた状態の完全バックグラウンド歩行を保証しません。採集の既存バックグラウンド処理とは分離しています。

## 設定は車両画面から

1. 通常の「車両登録」で自分のバン／トラックの荷台を登録します。
2. 今使う作業モードを選び、作業可能な現場に立ちます。石洗いの教示・試走時は未洗浄石を持ってください。
3. 「徒歩ルート・音声設定（EXEのみ）」→「往復を教える」を選択します。
4. 記録開始後、**W/A/S/Dとマウスだけ**で荷台へ歩きます。ダッシュ、乗車、ジャンプ、UI操作は記録しません。
5. **4秒以内ごとに立ち止まり、約1秒そのまま待つ**と照合点を保存します。照合点では上下視点を正規化するためカメラが動きます。カメラ補正・撮影中は歩き出さないでください。F6で照合点、荷台前の終点でF7。F9で取消です。
6. 荷台IDを確認後、復路の記録が始まります。同じ現場まで戻ってF7を押します。
7. もう一度パネルを開き、現場で「自動試走（収納しない）」を実行します。**往路再生→登録荷台を実際に開く→復路再生→作業ボタン確認**が成功した経路だけ有効になります。試走ではアイテムを動かしません。
8. 自動収納をONにしてFarmを開始します。

石掘り・砂金・石洗いは別々の往復を保持します。既存の荷台登録は消しません。車両を移動した、サーバーへ再接続した、ゲーム画面サイズ・カメラ設定が変わった場合は記録と試走をやり直してください。違う経路を推測して歩くことはしません。

## 本番の処理

- 石掘り／砂金：しきい値→入力停止→教えた往路を徒歩再生→荷台ID照合→確定した作業成果の収納→既存の数量台帳・metadata・操作レシート照合→教えた復路→作業ボタン→次の実報酬で再開確認。
- 石洗い：最後の未洗浄石0（または容量しきい値）→必要な後退アニメーション待ち→往路→洗浄で得た確定成果収納→荷台から未洗浄石を補充→復路→洗浄対象確認→次の実消費・報酬で再開確認。

補充量は荷台在庫、重量、スロット、次の報酬の余裕から計算します。「重量が100%になるまで詰める」方式ではありません。今回の作業で獲得したと証明できない食料・道具などを勝手に収納しません。荷台満杯、石在庫0、不確定な移動要求は既存の安全停止を維持します。

**歩行入力の送信成功は到着の証拠ではありません。** 各区間末尾で景色を照合しますが、画像一致も世界座標の厳密な証明ではありません。最後は独立した荷台ID／作業対象の確認が必要です。照合失敗・入力拒否・遅延・途中取消で、未完了区間を盲目的にもう一度再生することはありません。

## 完了ボイス

事前生成した音声をEXEに埋め込みます。利用PCで音声合成エンジンを入れたり、APIキーを設定したりする必要はありません。

**音声：VOICEVOX:四国めたん**。「アニメ調・甘め（あまあま）」と「クリアな女性音声（ノーマル・初期値）」、音声OFFを切り替えられます。

- 石掘り：「石掘りが終わったよ」
- 石洗い：「石洗いが終わったよ」
- 砂金：「砂金取りが終わりました」

既定は満杯で収納へ移るとき／実際に最後の未洗浄石を消費したとき。パネルで「作業が1回成功するたび」に変更可能です。失敗やF9中止を成功扱いして読み上げません。音声は非同期であり、再生終了まで収納を待たせません。

音声利用・再配布時は `src/audio/CREDITS.txt`、`voice-manifest.json` および以下の規約に従ってください。再利用を許諾する際は同じ遵守義務を引き継いでください。

- https://voicevox.hiroshiba.jp/term/
- https://zunko.jp/con_ongen_kiyaku.html

音声モデルや合成エンジン自体は配布しません。固定の無害な通知文だけを生成しています。音声ファイルは各ファイルのSHA-256をビルド時に検証します。

## 制約と診断

景色が似通う地形、真っ暗な場所、時間帯・天候の大きな変化、他プレイヤーや車両による遮蔽、NavMeshではなく物理的に通れない経路、負荷による入力落ちなどは実機で調整が必要です。見えない任意のトラックを全環境で確実に追跡するものではありません。

`EXE_ROUTE` に各区間・結果、`EXE_ROUTE_UNVERIFIED` に途中停止、`EXE_ROUTE_CARGO_NOT_VERIFIED`／`EXE_ROUTE_WORK_NOT_VERIFIED` に終点不一致を記録します。ルートはSaved Games内のアプリデータ配下 `exe-routes/<mode>/` に保存します。Raw Inputは明示的な教示中・対象ゲーム前面時の移動だけを処理し、他アプリの文字入力や任意のキーを保存しません。景色の縮小グレースケール画像はローカル保存のみです。

## 検証の区別

自動試験は画像照合の合成画像テスト、経路データの境界値、実運用と共通の区間オーケストレーターへの模擬入力、取消後の無入力、照合失敗後の再走禁止、音声の実バイト、既存収納・補充・保存などの回帰試験です。

**開発用Windowsでビルドが成功しても、ユーザーのFiveM環境での成功を代替しません。** 配信済み安定版とは分けて試験候補を提供し、各PCの実試走が成功するまで徒歩収納を有効にしません。
