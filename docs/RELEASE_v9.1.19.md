# AI採掘機 v9.1.19 — 荷台前エンドレス石洗い

概要画面に「荷台前エンドレス石洗いを開始」を追加しました。これは、車両画面で自動収納を有効にして荷台を登録し、FiveM上で「石を洗う」とその登録荷台の操作が同時に表示される位置から使う専用モードです。通常開始と高速石洗いは従来どおり移動を行わず、この専用モードだけが限定的な位置・視点補正を使用します。

洗浄報酬を確認した後は、ゲーム側の後退動作が止まるまで1.15秒待ちます。その後、前後の移動入力は1回80ms以下、視点補正は1回までに制限し、各入力の前後で接続セッション、作業進捗、インベントリが閉じていること、「石を洗う」と登録荷台の構造を再観測します。「荷台だけ」なら洗浄位置側へW、「洗浄だけ」なら荷台側へSを50ms送り、入力後の観測で次の方向を毎回決め直します。どちらも見えない場合だけ、最後に確認できた範囲の周囲を回数制限付きで前後探索します。3回連続で安定したことを確認できた場合だけ次の洗浄へ戻ります。固定座標や録画した徒歩ルートではなく、その時点のDOM観測結果を使う軽量な閉ループです。

満重量または未洗浄石0を確認した場合は、検証済みの成果物だけを同じ登録荷台へ収納し、所持できる範囲で未洗浄石を補充します。収納・補充の前後でも登録車両の識別子と種類、実際の所持数差分を確認し、洗浄を再開する直前には洗浄操作と荷台操作の両方を再観測します。候補が複数ある場合や転送結果が曖昧な場合に続行しません。

補正には回数と時間の上限があります。手動入力、FiveM接続セッションの変更、対象ウィンドウの消失、入力解放失敗、複数候補などの安全条件に触れた場合は入力を解放して停止します。それ以外でも上限内に開始地点へ戻れなければ入力を全解放し、同じ専用モードを1回だけ再始動します。再度失敗した場合は停止します。補正中もF9で停止できます。

この機能は一般的な自動移動・経路探索ではありません。開始位置周辺の前後ずれと軽い視点ずれだけを対象とし、車両の大きな移動、180度の向き直し、障害物の回避、別の洗浄場所や荷台の探索は行いません。「エンドレス」は、同じ開始条件が保たれる間に洗浄・収納・補充を繰り返すモード名であり、無期限の連続動作を保証する意味ではありません。

ローカル検証では、実装されたAHK/C#経路、5種類のDOM状態、短時間入力の上限、3回連続の安定確認、登録荷台だけを使う条件、1回限りの再始動、安全停止、UI操作を確認しています。一方、このリリース作業環境から実FiveMサーバーへ接続した連続洗浄は実施していません。実サーバー固有のox_target文言・DOM更新間隔・アニメーション時間・ネットワーク遅延・車両差による挙動は未確認です。
