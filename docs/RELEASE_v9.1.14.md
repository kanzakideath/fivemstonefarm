# AI採掘機 v9.1.14 — 荷台前の再開条件と洗浄間待ちを修正

## 停止理由への対応

前版では前進後に景色の一致度が下がると、実際の洗浄・荷台の操作可否を確認せず停止しました。景色の一致度は三人称カメラ等の影響を受けるため、それ単独をプレイヤーが逆方向へ動いた証明とはしません。

確認済みの近接収納・石洗いは専用 `wash-service` へ進みます。直前の洗浄の実報酬・未洗浄石消費を確認した場合だけ、以下を実行します。

1. 現在の接続に結び付いた実NUIから、洗浄進捗終了・所持品画面が閉じた状態・洗浄と荷台の同時利用可能性を3回確認。
2. 静止した景色に開始時からのずれがある場合だけ、30〜80msのWを最大1回送信。カメラ回転や追加追い込みはしません。ずれが許容範囲内なら入力0回。
3. Wを解除して画像観測を保存した後、もう一度実NUIの再開条件を確認。両操作が使えれば、景色の完全一致を要求せず次の洗浄へ進みます。石0なら洗浄ボタンを要求せず荷台側の確認から既存の補充へ。
4. 次の洗浄は従来どおり単発クリック・進捗監視・石消費と成果増加を確認。荷台ID、転送数量、二重送信防止も維持します。

`WASH_SERVICE` は入力処理が終わっただけを意味し、位置復帰・収納・洗浄成功ではありません。手動操作、前面喪失、接続変更、キー解除失敗、操作範囲の喪失では続行しません。一般の徒歩ルート・通常の画像補正の厳格な停止条件は変更していません。

## 待ち時間と表示

荷台前では古い景色へ収束するまで何度も前進・480ms静止確認を繰り返す処理を使わず、1回の限定入力と次の操作が本当に可能かの確認を使います。既知の制御ポートは再利用し、各洗浄の前に応答しない別ポートの探索を繰り返す時間を減らします。ゲームの洗浄アニメーション、クールダウン、報酬制限は短縮しません。実ゲームでの最短秒数や倍率は未測定です。

前進補正ON時にバックグラウンドだけで動くように見える表示を修正し、停止後や他アプリ前面で古い稼働オーバーレイが残ることを防ぐ再確認を追加しました。

## 診断

既存診断ZIPに `WASH_TASK_READY/WAIT`、`WASH_SERVICE_END`、`WASH_DISPATCH_BEGIN/END` が追加されます。NUI待ち・位置調整・次の洗浄の所要時間を分けて追えます。画像の誤差と作業再開の確認は別の記録です。診断は自動送信しません。

## 更新後

F9で停止して更新。「作業位置と視点を自動復旧」と「自動収納・補充」をONにし、登録荷台前で「この位置で近接収納を確認（歩かない）」を確認します。未洗浄石を持ち、FiveMを前面にして開始してください。手動更新ではEXEだけ置き換え、自分のINIは上書きしないでください。

## 検証範囲

完成EXE、状態遷移・NUI式・合成画面への実W入力・停止とキー解除・旧更新プログラム互換を検証します。実FiveMのカメラ追従、連続収納・補充、全条件での速度と成功率を測定したものではありません。最初の数回と補充を見届け、不具合時は診断ZIPを保存してください。
