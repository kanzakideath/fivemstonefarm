釣りアシスト 0.3.0-preview
=============================
独立したWindows版です。旧採掘機のmain・公開Release・更新先には変更しません。
既存のFishingPilot設定・ログは %LOCALAPPDATA%\FishingPilotPortable を使用します。

更新・起動
----------
旧FishingPilotと旧採掘機を終了し、ZIPを新しいフォルダーへすべて展開してください。
FishingPilot.exeだけを古いフォルダーへ移さないでください。UI・DLL・SceneProbe.jsも必要です。
FishingPilot.exe を実行します。Windows 10/11 x64、.NET Framework 4.8、WebView2 Runtime用。
前の採掘ツールが使えていたPCではWebView2が既にある場合があります。
この版は自動アップデートではなく、一式ダウンロードして起動する試用版です。

設定画面で「観察テスト」OFF、「バックグラウンド動作」ONにして設定を保存します。
2番に釣り竿、指定ホットバーに食料・飲料を用意し、FiveM上でF8で開始、F9で停止します。
画面の開始ボタンは3秒後に開始します。押した後ゲームへ戻ってください。
初回の観察テストONでは実入力しません。既存設定のON/OFFを勝手に変えません。

今回の変更
----------
1. 描画中の円・数字を読み、その場で緑の内側を確認して通常の数字キーイベントを送ります。
   対応NUIでは判定の途中に別画面探索や入力前の二重読み取りを挟みません。
   同じ数字の追加判定、円のリセット、二重入力防止は維持します。
   ゲームの成功処理・報酬・アニメーション速度を書き換える機能ではありません。
2. 比率指定のSVG中心、拡大縮小・画面サイズ、円弧の回転を描画値から読み取ります。
   前面画像の場合も正規化と上限付き遅延補償を使います。
3. 裏画面ではFiveMが所有する一意なDevConポートを確認して登録ホットバーを使用します。
   数字は検出したゲームUI要素からkeydown/keyupを送ります。別アプリへのOS入力はしません。
4. Framework7 9.1.3 iOSテーマ + WebView2で画面を作り直しました。
   左に概要・設定・診断ログ・更新情報。白い設定リスト、青い開始ボタンを使います。
   入力方式、読み取り時間、入力後の画面変化を表示します。

継続する機能
------------
釣果または終了を観測してから次の投竿へ。追加判定中に竿を再使用しません。
重量上限または空き余裕（既定500g）で音声・画面通知し、新しい投竿を保留します。
空腹・水分を別々に監視し、50%以下で必要な側だけ補給し、回復を確認します。
ゲージ位置が不明なら停止中に空腹へマウスを合わせCtrl+Alt+F6、水分はCtrl+Alt+F7。
読み取り不明を満タン扱いにしません。食料・飲料がない場合に餓死を防ぐ保証はありません。
自動収納・移動・カメラ変更はありません。ミニゲームはこの独立アプリにはありません。

裏画面の条件
------------
FiveMをウィンドウまたはボーダーレスにし、最小化せず他のアプリへ切り替えてください。
対応するNUI・登録ホットバーに依存します。非対応UI、ゲーム側の処理停止、最小化、
ロック画面・スリープ中の継続は保証しません。無効な入力を成功扱いにしません。
「入力後の画面遷移」は画面変化の観測であり、魚の取得やサーバー受付の証明ではありません。
入力イベントを受け付けないNUIでは進まないことがあります。別アプリへの入力fallbackはありません。
接続変更・F9で停止します。再起動後はF8で明示再開します。

診断・データ
------------
停止後「診断ログ」→「診断ZIPを保存」で書き出します。
バージョン、実行セッション、円の角度、キー送信、結果、待機理由、読み取り時間を記録します。
ログは4MiB×2世代。画面や一般的な文字入力を保存せず、自動アップロードもしません。
トレイのメニューから停止・診断保存も行えます。共有前にZIPの中身を確認してください。
他の人からの所持品増加を釣果と区別できないことがあるため、同時にアイテムを受け取らないでください。

検証範囲
--------
Windowsの自己テスト、合成デスクトップ上のキー入力、WebView2の実描画と本体メッセージ接続、
実SceneProbe.jsを使うSVG解像度・入力試験、ブラウザーUI試験をビルド時に実行します。
合成テストと実FiveMは別です。長時間成功率・最短サイクル・完全無失敗は実地未検証です。
最新版でもサーバー固有の画面変更・タイミング・バックグラウンド受付で追加調整が必要な可能性があります。
ソースは同梱Build.ps1 -Testで再ビルドできます（.NET SDK、Node.jsが必要）。
